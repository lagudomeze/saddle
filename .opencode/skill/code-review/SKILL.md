# Rust 代码审查流程

## 审查范围

### 1. 错误处理
- [ ] 是否避免在库代码中使用 `unwrap()`、`expect()`
- [ ] 是否正确使用 `?` 运算符传播错误
- [ ] 自定义错误是否实现了 `std::error::Error`

### 2. 生命周期
- [ ] 引用是否正确标注生命周期
- [ ] 是否存在悬垂引用风险
- [ ] 结构体引用的生命周期是否合理

### 3. 并发安全
- [ ] 多线程共享数据是否使用 `Arc<Mutex<T>>` 或 `RwLock`
- [ ] 是否存在数据竞争
- [ ] Send/Sync trait 是否正确实现

### 4. Unsafe 代码
- [ ] unsafe 块是否有注释说明原因
- [ ] 是否满足 unsafe 块的约束条件
- [ ] 是否进行了必要的边界检查

### 5. 性能
- [ ] 是否存在不必要的克隆
- [ ] 是否正确使用迭代器而非手动循环
- [ ] 是否避免了不必要的堆分配

## 输出格式

```markdown
## 审查报告

### 问题
- [file:line] 严重程度: 描述
  - 问题详情
  - 建议修复

### 建议改进
- [建议内容]

### 通过项
- [通过的审查项]
```
